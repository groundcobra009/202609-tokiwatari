# 時渡り（Tokiwatari）— デモ台本（3分）

チーム16・発表者: けいたろう
公開URL: `https://tokiwatari.keitro-aigc.com`（デプロイ前は `http://localhost:3000`）

## タイムテーブル

### 0:00〜0:30 タイムラインを開く

- **操作**: 公開URLを開く。画面中央に「今」の線があることを指す。マウスホイールを軽く下に回し、少し戻す
- **画面で起きること**: ダーク基調のタイムラインが表示され、「今」の線を境に投稿カードが並ぶ
- **セリフ**: 「これが時渡りのタイムラインです。真ん中の線が『今』。下にスクロールすると過去、上にスクロールすると未来に行きます」

### 0:30〜1:30 過去へ行き、当時の本人に返信する

- **操作**: 左（または上部）の年ジャンプナビで「2023」をクリック。生成AIに出会った頃の投稿カードを1つ選ぶ。「この時点に返信」を押し、入力欄に **「それ、今どうなった？」** と入力して送信
- **画面で起きること**: 2023年の投稿群が中央に表示される。返信フォームが開き、送信後にAIの返答が表示されるまで数秒待つ。返答カードに「当時の本人（AI再現）」ラベルが付く
- **セリフ（送信直後の待ち時間用）**: 「今、2023年のけいたろうが、当時の投稿を読み返して考えています」
- **セリフ（返答が出たら、読み上げる）**: 「当時のけいたろうの口調で、当時の考え方のまま返事が返ってきました」

### 1:30〜2:20 「今」に戻り、未来へ投稿する

- **操作**: 年ジャンプで「今」をクリックしてタイムラインの中央に戻る。「未来へ投稿」フォームに日付 **2036-09-13**、本文 **「10年後の自分へ。今日ハッカソンで『時を超えるSNS』を作った。まだ続けてる？」** を入力して送信
- **画面で起きること**: 送信後、数秒の待ち時間ののち「未来の自分（AI推定）」ラベル付きの返答カードが未来側に表示される
- **セリフ（送信直後の待ち時間用）**: 「これまでの投稿全体から、未来のけいたろうをAIが推定しています」
- **セリフ（返答が出たら、読み上げる）**: 「未来の自分から返事が届きました。これはAI推定だと画面にも明示しています」

### 2:20〜2:40 他メンバーのタイムラインに触れる

- **操作**: 画面上部のユーザー切り替えで「しゅんた」または「やかん」のタイムラインに切り替える（実演せず口頭のみでも可）
- **画面で起きること**: 別メンバーのタイムラインが同じ構成で表示される
- **セリフ**: 「同じことが、しゅんたさんややかんさんのタイムラインでもできます。種になっているのは、それぞれ自分の過去投稿です」

### 2:40〜3:00 まとめ

- **操作**: 「今」の線に画面を戻す
- **セリフ**: 「思考が時を超えて往復する。それが10年後のあたりまえだと考えています。以上、時渡りでした」

## デモ前チェックリスト

- [ ] 種データ（けいたろう20件・しゅんた6件・やかん6件）が投入済みか
- [ ] Claude APIキーが本番環境（Cloudflare secret）に設定済みか。ローカルの`.dev.vars`とは別に確認する
- [ ] 公開URLがデプロイ済みで実際にブラウザから開けるか、直前に1回通しで確認したか
- [ ] AI返答は5〜10秒かかる想定。待ち時間用のセリフ（上記「送信直後の待ち時間用」）を用意済みか
- [ ] **失敗時のフォールバック**: APIエラー・タイムアウトが起きた場合は、事前に取得したモック応答（同じ文言での返答スクリーンショット）に切り替えて見せる。スクリーンショットは発表用PCのデスクトップにすぐ開ける状態で置いておく

## 入力文言の候補

### 返信（過去の本人への返信・3つ）

1. 「それ、今どうなった？」（2023年の生成AI関連投稿への返信・本編で使用）
2. 「あの時の不安、今はどうなってる？」
3. 「今の自分から見て、あの判断は正しかったよ」

### 未来投稿（未来の自分への投稿・3つ）

1. 「10年後の自分へ。今日ハッカソンで『時を超えるSNS』を作った。まだ続けてる？」（本編で使用・宛先2036-09-13）
2. 「今、迷っていることがある。10年後の自分はどう考えているか教えてほしい」
3. 「今日決めたことを、10年後も続けられているか知りたい」
