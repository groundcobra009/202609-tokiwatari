## 失敗時の進行

- 過去返信が失敗した場合：入力は残るので通信復旧後に再送する。成功を装わず、次の体験へ進む。
- 未来投稿は保存できてもAI生成に失敗する場合がある。エラー時は「本文は保存、返答は未生成」と伝える。連打で投稿を重複させない。
- mockは操作確認用。liveと同じ品質を示す証拠として使わない。
- 本番が開かない場合はローカルで実演し、提出リンク未確認の状態を明示する。

## 比較画面を使う実演（DEC-018以降）

1. ホームの「けいたろうのサンプルで比べる」を選ぶ。手書きのデモ記録と伝える。
2. 「1 · 過去に聞く」を押す。2023年の投稿の返信欄に入る共通の問いを送る。
3. 返答の「AIに渡した記録」を開き、対象日以降の記録がないことを見せる。
4. ホームの「2 · 未来に聞く」を押し、同じ問いを2036年へ投稿する。
5. ヘッダーの「返事を比べる」で2つの視点を並べる。未来側は現在までの記録を参考にし、過去側とは知っている範囲が違うと説明する。
6. 「今日の一歩を自分の言葉で残す」を押し、今日の日付の投稿欄へ戻る。「どちらの言葉を今日の一歩に使うか」を本人の言葉で残して体験を結ぶ。一覧は入力した記録であり、全件を引用した証明ではないと必要に応じて説明する。

比較はこの画面で生成した返答を並べる。再読み込み後も投稿と返信は残るが、比較表示は再生成が必要。待ち時間は進行表示が出るので、時間の違いを説明しながら待つ。mock表示なら操作デモであり、実AIの品質を実演したと主張しない。


### DEC-019以降の入力UI

比較の入口は「使い方 · 過去と未来を比べてみる」を開く。通常は「今の記録」で本文を書き「投稿する」。未来の対話は「未来の自分に聞く」へ切り替え、本文を書き同名の送信ボタンを押す。公開日時は「公開設定」にあり、未来のAIが想像する年とは別。今日の一歩は日付入力なしで保存できる。
