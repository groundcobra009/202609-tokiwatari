チーム16・発表者: けいたろう

## スライド1

### 10年後は、思考が時を超えるのが当たり前になる

- 朝起きたら、10年前の自分から返事が届いている
- 過去に書いたことが、今日読む前提で待っている
- 未来に書いたことが、その日が来たら本人に届く
- タイムラインは「今」だけでなく、過去から未来まで伸びている
- これを1日で動くSNSとして作った。名前は「時渡り」

**話す内容（30〜45秒）**
朝起きたら、10年前の自分から返事が届いている。そんな朝を想像してみてください。今日のテーマは「10年後のあたりまえ」です。私たちは、思考が時間を超えて行き来するのが当たり前になる未来を考えました。物理的に時間を移動するのはまだできません。でも、その時に考えていたことは、時間を双方向に渡れるようになる。それを1日で動くところまで作ったのが「時渡り」です。

## スライド2

### 3つの体験 — タイムラインは、往復する

- **時間座標つきタイムライン**: すべての投稿が「いつの思考か」を持ち、下へスクロールで過去、上へスクロールで未来、年ジャンプで一気に移動
- **時間越しの返信**: 過去の投稿に返信すると、その前後の投稿を文脈にしたAIが「当時の本人」として返事をする
- **未来からの手紙**: 未来の日付宛てに投稿すると、これまでの思考全体から推定した「未来の自分」が返事をする
- 今のSNSとの違いは一言で言えます。**今のSNSは一方通行、時渡りは往復する**

**話す内容（30〜45秒）**
体験は3つです。1つ目、すべての投稿は時間座標を持っていて、タイムラインを下にスクロールすると過去、上にスクロールすると未来に行けます。2つ目、過去の投稿に返信すると、当時のその人がAIで再現されて返事をします。3つ目、未来の日付に投稿すると、これまでの思考から推定した未来の自分が返事をくれます。タイムカプセルや予約投稿は送るだけの一方通行ですが、時渡りは往復するところが違います。

## スライド3

### デモと根拠

**デモで見せるもの**
- 2023年の投稿に「それ、今どうなった？」と返信し、当時の本人（AI再現）が答える
- 2036年宛てに投稿し、未来の自分（AI推定）から返事が届く
- 同じ仕組みで、しゅんた・やかんのタイムラインも動く

**10年後に当たり前になる根拠**
- 発信ログは増え続ける。SNS・チャット・音声メモで、10年分の思考が誰にでも蓄積される
- 人格の再現精度は上がっている。本人の言葉が十分にあれば、当時の考え方を再現できる技術はすでに手の届く距離にある
- 「未来に書く」文化が、日記や手紙の延長として定着していく

**技術構成**: Next.js + Cloudflare Workers（KV）+ Claude API

**話す内容（30〜45秒）**
デモでは3つ見せます。2023年の投稿に返信して当時の本人から返事をもらうところ、2036年に投稿して未来の自分から返事が届くところ、そして同じ仕組みが他のメンバーのタイムラインでも動くところです。10年後に当たり前になると考える理由は3つ。発信ログは増え続けること、人格の再現精度が上がっていること、そして「未来に書く」文化が日記や手紙の延長として根づいていくことです。技術構成はNext.js、Cloudflare Workers、Claude APIで、今日1日で組みました。

## Q&A想定

**Q1. 他人の過去投稿を勝手に使うのは問題では？**
A. 使うのは本人の投稿だけです。今日のデモも、けいたろう自身とチームメンバー本人の過去投稿だけを種にしています。他人の投稿を本人の同意なく取り込むことはしません。

**Q2. 未来の自分の返事は当てずっぽうでは？**
A. その通りで、これはAIによる推定だと画面上に明示しています。過去の思考の延長線上にある「今の時点で考えられる未来の自分の言葉」として提示するもので、予言ではありません。

**Q3. 今のSNSの予約投稿・タイムカプセル機能と何が違うのか？**
A. あれらは未来へ送るだけの一方通行です。時渡りは、過去の自分が当時の口調で返事をし、未来の自分からも返事が来る。つまり往復する点が違います。
