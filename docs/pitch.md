# タイムトーク — 5分発表の構成

チーム16・発表者：けいたろう。公式の発表5分＋質疑1分に合わせる。
現在の実装を説明する原稿。実AIの品質と利用者の反応は、確認した結果だけを加える。

## 0:00〜0:40 誰の、どんな迷いを助けるか

「新しいことを始めたい。でも、一歩踏み出すか迷っている。以前も同じように迷っていたはずなのに、日記やSNSを探すだけでは、今の問いに答えてくれません。
タイムトークは、記録を読み返すところから、その時の自分に話しかけるところへ進めます。過去の視点と未来の視点から、今の考えを言葉にするためのSNSです。」

## 0:40〜3:40 実演

[3分デモ台本](demo-script.md)に従う。手書きサンプルであることを最初に伝える。
AI表示がmockなら「ここでは定型応答で操作を確認しています」と明示する。liveの口調再現や品質を確認したことにはしない。

## 3:40〜4:15 AIが必要な理由と限界

「日記は過去の文章を読み返します。予約投稿は未来の日時に文章を届けます。タイムトークでは、過去の記録に今の問いを返し、未来の視点からも問い直せます。
過去の返事には、その投稿時点までの記録だけを渡します。未来の返事には現在までの記録を渡します。AIの出力や未来宛ての希望を、実際に起きた出来事として再利用しません。
それでも本人そのものでも予言でもありません。記録に基づく再現・推定として表示します。」

## 4:15〜4:50 最初の導入と育て方

「最初は、転職・独立・新しい活動を考えていて、日記や発信の習慣がある人に使ってもらいます。次は本人が書き出した日記の取り込みです。自分の記録だけを、自分の同意で選べるところから始めます。
1週間後にも使いたいか、実際に再訪するか、返事の根拠が納得できるかを確かめます。家族への記録や知識継承への展開は、その後の仮説です。」

## 4:50〜5:00 結び

「過去を読むだけで終わらせず、未来を待つだけでも終わらせない。思考が時を超えて往復する。その入口が、タイムトークです。」

## 質疑への回答

- **本物の過去投稿か**：今日は手書きのサンプル35件です。取り込み画面は準備中で、外部SNSとの連携はありません。
- **未来に通知が来るか**：現在は未来の時間座標に投稿し、その場で返答を生成します。公開日時までは他の人に本文を伏せます。配送・通知は未実装です。
- **非公開は安全か**：APIで本文を伏せ、AIにも別の非公開記録を渡しません。ただしキーなしのゲストは共有デモです。本当の秘密は入力せず、実利用には本人認証・友人関係・管理者権限の整備が必要です。
- **本人になりすまさないか**：画面でAI再現・AI推定と区別します。実利用版では本人同意と公開名の設定を必須にする計画です。
- **技術**：Next.js、Cloudflare Workers/KV、Claude API。キーなしでもmock/guestで動きます。

## 最初の検証計画（実施前の仮説）

| 項目 | 方針・判定方法 |
|---|---|
| 最初の対象 | 転職・独立・新しい活動を検討し、半年以上の日記や発信がある人。まず本人同意のある5人を募集する計画。導入先は未確約 |
| 取り込み | 初回は本人がエクスポートした日記テキスト。日時・本文をプレビューし、選択して確定。X/note自動連携は後段 |
| 本人同意 | 記録の本人確認、AI提供先への送信説明、利用目的への同意。第三者の私的会話は初回対象外 |
| 認証 | ゲストの共有IDを解消し、本人のIDで所有。Google名をそのまま公開せずニックネームを設定。既存デモと本人データは自動統合しない |
| 保存 | 試用は7日間・非公開を初期値にする案。撤回・書き出し・保存期限・運営者権限を設計してから実データを受け入れる |
| 費用 | 1人あたり生成回数・入力/出力トークン・応答時間を測定。予算上限到達時は生成を停止し本文保存は継続する案。料金と許容額は試用前に確認し、現時点で金額を約束しない |
| 成功指標 | 5人中4人が支援なしで往復操作を完走、3人以上が7日内に再訪し考えの変化を説明。これは計画上の目安で、達成済みの数字ではない |
| 停止条件 | 他人の本文混入、本人同意の欠落、撤回不能が1件でもあれば実データでの試用を停止 |
| 検証順 | デモの初見完走→同意/認証/保存の整備→本人の日記取り込み→実AIの比較検証→7日試用→継続判断 |

家族への記録は、本人以外の同意・閲覧権限・死後の扱いを解決してから検討する。機能の実装済み宣言ではない。

## 当日の審査に向けて、実例で示す3つのポイント

### 価値：この人が何を持ち帰るか

「新しい活動を始めるか迷っている人が、昔も何を怖がり、どう踏み出したかを言葉にする。正解をAIに決めてもらうのでなく、今の判断に使う視点を持ち帰る体験です。」

### 新規性：同じ問いを時間の両側から聞く

過去には「踏み出すとき何が不安だった？」、未来には「今の一歩をどう考える？」と問いかける。2023→2036の画面切替を見せる。「時刻を変えて投稿できる」だけでなく、「応答する視点と参照できる記録が変わる」と説明する。通知や予約配送の実装を主張しない。

### AI：実際の記録と返答のつながり

実検証では、過去の記録「言葉にしないと始まらない気がして」が未来の返答に引用された。2023年の自分に2026年の法人化を既知の実績として語るよう誘導しても「未来のことは分からない」と返した。履歴0件では「材料がないので断定できない」と返した。
この3例を根拠に、時間による文脈選定と情報不足の扱いを説明する。1回の成功を万能な安全性・人格再現の証明にはしない。原文はlive-eval.jsonを参照する。
